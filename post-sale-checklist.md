# Meridian Smile Studio — Post-Sale Checklist

## 30-Day Check-In

### Website Health

- [ ] Site loads in under 3 seconds on all devices
- [ ] No console errors in browser
- [ ] Form submissions working correctly
- [ ] All links functional (no 404s)
- [ ] Mobile responsive at all breakpoints
- [ ] SSL certificate valid

### Analytics & Tracking

- [ ] GA4 collecting data correctly
- [ ] Conversion events firing (consultation_submit, phone_call_click)
- [ ] Search Console verified and sitemap submitted
- [ ] No crawl errors in Search Console
- [ ] First month traffic baseline established

### Content

- [ ] All placeholder content replaced with final copy
- [ ] Blog has at least 2 posts published
- [ ] GBP has at least 8 posts published
- [ ] No lorem ipsum or placeholder text remaining
- [ ] All images are final (or clearly labeled placeholders)

### SEO

- [ ] 5+ local citations built
- [ ] Google Business Profile fully optimized
- [ ] First 5 reviews received
- [ ] Keyword ranking baseline established
- [ ] Schema markup validated

### Client Satisfaction

- [ ] 30-day check-in call completed
- [ ] Any issues or requests documented
- [ ] Client knows how to request content changes
- [ ] Client has admin guide and contact info

## 60-Day Check-In

### Performance

- [ ] Organic traffic growing month-over-month
- [ ] At least 1 consultation request from organic search
- [ ] GBP views increasing
- [ ] Review count growing (target: 15+ by day 60)
- [ ] Average review rating 4.8+

### Content

- [ ] 4+ blog posts published total
- [ ] GBP posting schedule maintained (4x/month)
- [ ] Blog traffic contributing to site traffic
- [ ] At least 1 blog post ranking for target keyword

### Technical

- [ ] No new security issues
- [ ] Page speed maintained (LCP < 2.5s)
- [ ] Core Web Vitals all "Good"
- [ ] No new schema errors

### Client Satisfaction

- [ ] 60-day check-in call completed
- [ ] Content update requests handled promptly
- [ ] Client understands analytics reports
- [ ] Client knows how to respond to reviews
