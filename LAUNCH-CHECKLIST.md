# Meridian Smile Studio — Launch Checklist

## Pre-Launch (1–2 Weeks Before)

### Content

- [ ] All copy reviewed and approved by Dr. Cross
- [ ] No placeholder text remaining in any page
- [ ] No lorem ipsum anywhere
- [ ] All phone numbers, emails, and addresses verified
- [ ] Blog posts reviewed and approved
- [ ] Testimonials confirmed with patients (if real)

### Design

- [ ] All images replaced with final photography (or clearly labeled placeholders)
- [ ] Favicon replaced with proper .ico + .png files
- [ ] OG image created (1200x630px, branded)
- [ ] Logo finalized (SVG + PNG)
- [ ] Brand colors verified across all pages
- [ ] Typography renders correctly on Windows, Mac, iOS, Android

### Technical

- [ ] HTML validates (W3C Validator)
- [ ] CSS validates (W3C CSS Validator)
- [ ] No JavaScript console errors
- [ ] All links work (internal + external)
- [ ] Form submits correctly
- [ ] Form validation works (required fields, email format)
- [ ] Honeypot spam protection works
- [ ] Mobile responsive at 360px, 390px, 430px, 768px, 1024px, 1440px
- [ ] No horizontal scroll at any viewport
- [ ] Keyboard navigation works throughout
- [ ] Screen reader tested (VoiceOver or NVDA)
- [ ] Focus indicators visible on all interactive elements
- [ ] Skip navigation link works

### SEO

- [ ] Title tags unique per page (50–60 characters)
- [ ] Meta descriptions unique per page (150–160 characters)
- [ ] H1 tags present on every page (one per page)
- [ ] Image alt text present on all images
- [ ] Schema markup validates (Google Rich Results Test)
- [ ] sitemap.xml exists and includes all pages
- [ ] robots.txt exists and allows crawling
- [ ] Canonical tags present on all pages
- [ ] No duplicate content between pages
- [ ] Google Search Console verified
- [ ] Sitemap submitted to Search Console

### Analytics

- [ ] GA4 Measurement ID installed on all pages
- [ ] GA4 Realtime report shows live traffic
- [ ] Conversion events configured (consultation_submit, phone_call_click, etc.)
- [ ] Conversions marked in GA4 Admin
- [ ] Internal traffic excluded from GA4
- [ ] UTM parameters ready for marketing campaigns

### Deployment

- [ ] Vercel project connected to repository
- [ ] Custom domain configured (meridiansmilestudio.com)
- [ ] SSL certificate active (HTTPS working)
- [ ] Vercel headers configured (security headers)
- [ ] Clean URLs working (/blog not /blog.html)
- [ ] 404 page working (test with invalid URL)
- [ ] Redirects configured (if any)

---

## Launch Day

### Final Checks

- [ ] Site loads in under 3 seconds
- [ ] All pages render correctly
- [ ] Form submits and sends notification
- [ ] Phone number click-to-call works on mobile
- [ ] Email link opens mail client
- [ ] Social sharing shows correct OG image and description
- [ ] Google Business Profile updated with website URL
- [ ] Yelp listing updated with website URL
- [ ] Healthgrades listing updated with website URL

### Go-Live Steps

1. [ ] Push final code to repository
2. [ ] Vercel auto-deploys
3. [ ] Verify live site at meridiansmilestudio.com
4. [ ] Test all pages on live domain
5. [ ] Submit URL to Google Search Console for indexing
6. [ ] Update Google Business Profile website URL
7. [ ] Update all directory listings with live URL
8. [ ] Send launch announcement to email list (if applicable)

- [ ] Test form submission from live site
- [ ] Check page speed on live domain (PageSpeed Insights)
- [ ] Monitor for any security issues in Search Console
