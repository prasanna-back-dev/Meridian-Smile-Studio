# Meridian Smile Studio — SEO Strategy

## Goals

1. Rank in Google's Local Pack (top 3) for "cosmetic dentist san francisco" within 6 months
2. Achieve top 10 organic rankings for 5+ primary keywords within 12 months
3. Build domain authority from 0 to 25+ within 12 months
4. Generate 15+ qualified leads per month from organic search by month 9

---

## Strategy Overview

Meridian's SEO strategy has three pillars:

1. **Local SEO dominance** — Own the Google Business Profile, build citations, earn reviews
2. **Content authority** — Publish educational content that targets long-tail informational queries
3. **Technical foundation** — Fast, accessible, schema-marked site that Google can crawl and understand

---

## Pillar 1: Local SEO

### Google Business Profile (GBP)

- **Claim and verify** the GBP listing immediately
- **Category:** Primary: "Cosmetic Dentist" | Secondary: "Dentist," "Teeth Whitening Service"
- **NAP consistency:** Ensure Name, Address, Phone match exactly across GBP, website, and all citations
- **Photos:** Add 10+ high-quality photos (office, Dr. Cross, treatment room, results)
- **Posts:** Publish 1 GBP post per week (tips, offers, before/after with consent)
- **Reviews:** Implement a review generation strategy (see below)
- **Q&A:** Pre-populate GBP Q&A with common questions

### Review Generation Strategy

- **Target:** 50+ Google reviews within 6 months
- **Method:** Send a follow-up email/text 48 hours after each appointment with a direct review link
- **Template:** "Hi [Name], thank you for visiting Meridian Smile Studio. If you have a moment, we'd appreciate your honest review: [link]. It helps other patients find us. — Dr. Cross"
- **Respond to every review** within 24 hours (positive and negative)
- **Never offer incentives** for reviews (violates Google's terms)

| Platform | Priority | Notes |

### Local Content

- Create a "Serving San Francisco's Financial District" section on the homepage
- Include neighborhood references in blog posts (Montgomery BART, Battery St, California St)
- Add a Google Maps embed on the contact page
- Mention parking/BART details in location content

## Pillar 3: Technical SEO

### On-Page SEO Checklist

| Element | Requirement |
|---------|-------------|
| Title tag | 50–60 characters, primary keyword near front |
| Meta description | 150–160 characters, includes keyword + CTA |
| H1 tag | One per page, includes primary keyword |
| H2/H3 tags | Logical hierarchy, include secondary keywords |
| Image alt text | Descriptive, includes keywords where natural |
| Internal links | Minimum 2 per page, descriptive anchor text |
| URL structure | Short, keyword-rich, lowercase, hyphens |
| Schema markup | Dentist, LocalBusiness, FAQPage (where applicable) |

### Technical Requirements

| Requirement | Status | Notes |
|-------------|--------|-------|
| HTTPS | Required | Vercel provides by default |
| Mobile-friendly | Required | Responsive design implemented |
| Page speed | Target < 2.5s LCP | Inline CSS, minimal JS, optimized fonts |
| No broken links | Required | Check quarterly |
| XML sitemap | Required | sitemap.xml created |
| Robots.txt | Required | robots.txt created |
| Canonical tags | Required | Prevent duplicate content |
| No redirect chains | Required | Vercel clean URLs configured |
